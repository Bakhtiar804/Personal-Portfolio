## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies (if using React):

```bash
npm install
```

Run the development server:

```bash
npm start
```

Build for production:

```bash
npm run build
```
